# Projeto de Livros

Aplicação web desenvolvida em React para pesquisar livros, visualizar lançamentos e gerenciar livros favoritos.

## Funcionalidades

- Pesquisa de livros
- Listagem de últimos lançamentos
- Página de livros favoritos
- Adição de livros aos favoritos
- Remoção de livros Favoritos
- Integração com serviços/API para buscar e salvar dados

## Tecnologias utilizadas

- React
- JavaScript
- Styled Components
- Axios
- React Router DOM

## Como executar o projeto

1. Clone o repositório:

No terminal:
````
git clone https://github.com/HigorOliDev/Servidor-Alura-Books.git
````
3. Acesse a pasta do projeto

No terminal:
````
cd meu-projeto
````
3. Instale a dependencias

No terminal: npm install
````
react
react-dom
axios
styled-components
react-router-dom
````
## O projeto será aberto em http://localhost:3000

## Estrutura do projeto

## Sobre o projeto
Este projeto foi criado com o objetivo de praticar conceitos de React, como componentização, rotas, consumo de API, estado e renderização de listas. **Observação: para funcionamento completo do projeto é necessário a parte Front-end localizado em outro repositório.**
